New to Git and GitHub? This hands-on workshop introduces the fundamentals of version control and collaborative workflows, including issue tracking, pull requests, and code review. Participants will learn key Git concepts, practice using GitHub through the web interface, and optionally explore the same workflows from the command line.

**Lecturer:** [Toon Verstraelen](https://github.com/tovrstra) (Associate Professor, Center for Molecular Modelling)

This event is part of the [GhentCORR](https://ghentcorr.github.io/) & Coffee series, where we discuss topics related to Open and Reproducible Research in a relaxed setting with coffee, tea, and cookies.

**Register [here](https://event.ugent.be/registration/GitAndCoffee)**

### Target Audience

This workshop is intended for:

- PhD candidates and other early-career researchers who want to start using version control for code, data, manuscripts, or other research outputs.
- Researchers with little or no prior experience with Git.

### Programme

| Part | What you will learn | Pre-requisites |
|------|--------------------|---------------|
| **1. Introduction to Git and GitHub** | Why version control matters in research; key concepts and terminology | None |
| **2. Hands-on: GitHub in the browser** | Practice core GitHub workflows using the web interface: creating and editing files, making commits, working with branches, and contributing changes through pull requests | Bring your own laptop and have a GitHub account |
| **3. Advanced hands-on: Git and GitHub from the command line** | Perform similar Git workflows from a terminal: cloning repositories, staging and committing changes, and working with branches | Basic familiarity with the command line |

### Important notes

- Parts **1** and **2** are suitable for all participants.
- Part **3** covers the same core workflows using the command line and is intended for researchers with **prior terminal experience**.
- Participants are required to **bring their own laptop**.
